# Dentech — Developer Portfolio

A responsive portfolio website built with HTML5, CSS3, and vanilla JavaScript.

## Technologies
- HTML5
- CSS3
- JavaScript
- PHP and MySQL for selected application projects
- Git and GitHub

## Featured project concepts
- **BodaBodaGo:** ride-booking platform concept for Eldoret, Kenya.
- **County HR Portal:** county human-resource management system project.
- **AgriHub Africa:** agriculture-focused digital platform concept.

Project descriptions will be updated as implementation and testing progress.

## Run locally
Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

## Deployment
The site can be deployed as a static website on Vercel or another static hosting service.
